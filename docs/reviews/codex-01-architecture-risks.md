# Independent architecture review

1. **`_thread.interrupt_main()` has an unavoidable delivery race.** Checking `execId` under a lock does not make interrupt delivery atomic: `KeyboardInterrupt` may arrive after user code finishes and strike response serialization, cache invalidation, or the next request. Catching “stray” interrupts can also hide a legitimate cancellation. **Mitigation:** treat the worker as potentially poisoned after every forced interrupt; wrap the entire dispatch loop in recovery boundaries, acknowledge cancellation only after the main thread reaches a known-safe checkpoint, and restart when delivery cannot be proven complete. Prefer cooperative cancellation for traced Python code.

2. **`KeyboardInterrupt` can corrupt bookkeeping invariants.** It may interrupt namespace updates, Matplotlib capture, lock-held sections, or NDJSON writes, leaving partially updated state while the worker reports idle. **Mitigation:** keep user execution inside a narrow boundary; perform state publication transactionally afterward; use `finally` blocks for trace/stream/figure restoration; serialize complete messages through one non-interruptible writer path.

3. **Windows descriptor duplication needs explicit validation.** CRT descriptors, Win32 handles, text translation, and `sys.stdout` wrappers are distinct layers. `os.dup2()` may redirect CRT writes while libraries using cached Win32 handles behave differently; descendants may also retain protocol handles and prevent EOF. **Mitigation:** integration-test native `WriteFile`, C-extension writes, subprocesses, and all supported Python versions; set protocol descriptors to binary with `msvcrt.setmode`; make duplicates non-inheritable; rebuild `TextIOWrapper`s explicitly.

4. **Pipe backpressure can deadlock or freeze execution.** Large prints, native stderr output, figures, or a burst of trace events can fill stdout/stderr pipes. An 8 MiB per-message limit does not bound aggregate output or memory consumed while first constructing JSON/base64. **Mitigation:** continuously drain both pipes; use a single bounded writer queue, chunked stream events, per-execution byte quotas, truncation/drop notices, and size checks before full serialization.

5. **Concurrent protocol writers can corrupt NDJSON.** Reader-thread control handling and main-thread execution may emit responses/status simultaneously; buffering does not guarantee whole-line atomicity. **Mitigation:** only one dedicated thread may write protocol output; all producers enqueue structured messages carrying `session`, `execId`, and sequence number.

6. **Trace cost can become multiplicative.** Walking every frame’s locals and object graph on every line can turn a modest algorithm into millions of visits and large transient allocations before the final byte limit is checked. **Mitigation:** exclude non-user frames, apply budgets during traversal, cap depth and scalar/string sizes, deduplicate within/across snapshots, and encode deltas rather than complete heaps.

7. **Trace limits are not deterministic containment.** User code can catch the exception raised by the trace callback; blocking C calls still bypass line events. Snapshotting properties or unsafe object hooks could execute code. **Mitigation:** inspect only exact allowlisted container/layout primitives without attribute hooks; run traces in a disposable subprocess when hard time/memory limits matter; retain kill escalation.

8. **Handles are stale within a session.** `{session, name}` detects restarts but not deletion, rebinding, or an older UI request resolving against a different object with the same name. **Mitigation:** include a monotonically increasing namespace revision and object/view token in handles and responses; reject mismatches and suppress out-of-order UI responses.

9. **DataFrame cache invalidation is incomplete.** Invalidating on `execute` misses mutation through aliases, user-created background threads, extension inspection bugs, or objects sharing mutable backing data. Pandas exposes no reliable general mutation counter. **Mitigation:** create an immutable, bounded view snapshot for each sort/filter operation and page that snapshot; otherwise label results best-effort and avoid caching.

10. **Agg figure capture mutates global process state.** `sitecustomize` or prior imports may select another backend; pyplot managers persist across executions, so old figures may be resent or leaked. Rendering custom artists executes Python and huge DPI/dimensions can exhaust memory. **Mitigation:** record figure-manager identities before execution, capture only new/changed figures, cap pixels/DPI/output bytes before rendering, isolate failures, and define whether captured figures are closed.

11. **Live mode is not a security boundary.** AST heuristics are bypassable through aliases, dynamic dispatch, imports, threads, and indirect I/O; forced interruption is also ineffective in native code. **Mitigation:** require VS Code Workspace Trust and explicit per-workspace enablement, state that live code has full interpreter authority, rate-limit reruns, and use process restart—not interruption—as the hard-stop guarantee.
